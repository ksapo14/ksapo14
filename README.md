## Engineering beyond the abstraction line

I'm **Krish Sapovadia**, a web designer and aspiring AI/ML engineer focused on full-stack development, embedded systems, and human-centered computing. As **CTO at Imaginer**, I'm developing **IMAGINEv1**—a live assistant that transforms a teacher's or lecturer's speech into interactive visuals and concise summaries in real time. I enjoy understanding systems from first principles, then turning that understanding into products people can actually use.
